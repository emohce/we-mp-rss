# 外部内容连接器注册表

本目录定义 Intelligence Hub 面向托管聚合服务、RSS 服务、付费内容 API、AI 增强服务和投递平台的
统一接入边界。连接器扩展不能改变一个核心原则：`we-mp-rss` 与本地数据库仍是产品和事实源，外部
服务只能作为有来源标记、可停用、可替换的发现、补采、增强或投递通道。

## 能力分类

| Capability | 含义 | 默认方向 |
| --- | --- | --- |
| `discover` | 搜索公众号、网站或文章，返回外部身份 | 外部 → 本地 |
| `ingest` | 通过 RSS、Atom、JSON Feed 或受控 API 导入内容 | 外部 → 本地 |
| `subscription_sync` | 导入/导出订阅源、分组或 OPML | 单向优先 |
| `search` | 使用供应商索引进行全文或来源检索 | 外部 → 本地结果投影 |
| `enrich` | 摘要、关注点命中、分类或深度分析 | 外部 → 本地派生数据 |
| `deliver` | 将本地摘要、Feed 或通知交给外部服务 | 本地 → 外部 |
| `state_sync` | 同步已读、收藏或稍后读状态 | 默认禁用 |

每个连接器必须逐项声明能力，不能因为供应商有一个 CLI 或网站就推断其具备全部能力。

## 生命周期

| State | 允许行为 |
| --- | --- |
| `researched` | 只保存公开证据、限制和适配建议 |
| `contract-ready` | 字段、认证、配额、错误和幂等契约已核验，可写离线适配器 |
| `adapter-ready` | 适配器及假实现测试通过，真实调用仍关闭 |
| `canary` | 用户授权的单账号、单来源、低预算试运行 |
| `accepted` | 真实环境验收通过并有回滚/停用路径 |
| `disabled` | 认证、合同、价格、限频或安全边界不再满足 |

状态只能逐级提升；官网营销文案不能直接把连接器提升到 `contract-ready`。

## 风险分层

| Risk | 示例 | 门禁 |
| --- | --- | --- |
| R0 | 读取公开价格、文档、Feed 格式 | 无凭据只读核验 |
| R1 | 登录后列出订阅、搜索、读取摘要 | 用户完成授权；只读范围确认 |
| R2 | 添加/删除订阅、修改分组 | 变更预览、幂等键、显式确认 |
| R3 | 消耗按次 AI/API 额度 | 先查余额与预计成本，再逐批确认 |
| R4 | 不可逆已读、删除、公开且不可撤销分享 | 默认禁止；一次一项单独确认 |

后台计划任务只允许自动执行已授权的 R0/R1 操作。R2 以上不能因为定时任务、重试或 Agent 自动化
而获得隐式授权。

## 事实源、身份与同步

- PostgreSQL/SQLite 保存连接器安装、外部身份映射、游标、用量收据、验证快照和最后错误；Redis、
  MQTT 或 CLI 本地缓存均不是事实源。
- 每篇文章保存 `provider`、外部 `content_id`、规范 URL、抓取时间、供应商时间和派生数据版本。
- 同一文章可有多个外部身份，但只能映射到一个本地规范文章；不能仅按标题去重。
- 第一阶段只允许单向同步。启用双向订阅或分组同步前，必须定义字段所有权、冲突优先级、删除语义
  和回环抑制键。
- 已读、收藏、反馈与相关度默认留在本地用户域；只有供应商支持单篇可逆状态时才评审双向同步。

## 需要持久化的通用对象

后续实现采用以下逻辑对象；具体表结构需在实现批次单独迁移：

1. `connector_installations`：工作区、供应商、状态、凭据引用、能力快照和版本；
2. `external_source_identities`：供应商来源 ID、类型、规范来源 ID 和证据；
3. `connector_sync_cursors`：方向、资源、游标、ETag、最后成功检查点；
4. `connector_usage_ledger`：操作、幂等键、计费单位、余额、货币与供应商收据；
5. `provider_verification_receipts`：证据 URL、核验时间、版本/价格快照、下次复核时间和采用状态。

密钥、OAuth token、Cookie 和带密钥的 Feed URL只能保存为 `secret_ref`，不能进入日志、事件、MQTT
载荷或公开诊断接口。

## 当前注册表

| Provider | Role | State | 当前采用结论 |
| --- | --- | --- | --- |
| `we-mp-rss` | 核心公众号采集与 RSS | `adapter-ready` | 唯一产品核心；真实调用默认关闭 |
| 微信官方 API | 授权账号内容 | `researched` | 部署时按账号权限复核 |
| 通用付费 JSON API | 补采 | `adapter-ready` | 仅 HTTPS 允许域名和预算封顶 |
| SupSub | 托管聚合、发现、订阅同步、AI 增强 | `researched` | 先做 Feed/OPML/CLI 只读路径，不绑定运行时 |
| `Wechat2RSS` | 行为与限频参考 | `disabled` | 不作为运行时依赖，不复用受限服务 |

SupSub 的证据与分阶段采用决定见
[SupSub 服务与连接器核验](../research/supsub-integration.md)。后续供应商使用
[核验模板](provider-verification-template.md)，不得复制一套不兼容的临时字段。
